# Figure manifest

image file it was built from and the script that writes that image. The mapping
was produced by hashing each image embedded in the manuscript and matching it
against `figures/`, so it reflects what is actually in the document rather than
what the filenames suggest.

Figures 1 to 3 are supplied images rather than plots: the blisk CAD view and the
two generated diagrams. Archived copies are in `diagrams/rendered/`, and the
prompts used to generate the two diagrams are in `diagrams/`.
